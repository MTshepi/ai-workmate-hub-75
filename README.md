# WorkFlow AI

ROLE

You are an expert full-stack developer, AI engineer, prompt engineer and UI/UX designer.

CONTEXT

Build ONE integrated AI Workplace Assistant platform, not separate projects. The platform should solve common workplace productivity problems and demonstrate practical AI, prompt engineering, responsible AI and modern UI/UX.

STRUCTURE

Create one responsive dashboard with:

Sidebar navigation

Home dashboard

Smart Email Generator

Meeting Notes Summarizer

AI Task Planner

AI Research Assistant

AI Workplace Chatbot

Settings

Each feature must have a clear input → AI processing → output layout.

REQUIREMENTS

Include at least 3 AI features; preferably build all 5.

Email: generate Formal, Friendly or Persuasive emails.

Meetings: summarize notes and extract decisions, action items and deadlines.

Tasks: prioritize tasks and create daily/weekly schedules.

Research: summarize topics and provide insights/recommendations.

Chatbot: provide interactive workplace assistance.

Use structured prompts: Role + Context + Task + Requirements + Output Format.

Add a visible Responsible AI disclaimer stating that AI outputs may contain errors and should be verified.

Use a modern, professional, responsive UI for desktop and mobile.

Include loading, error and empty states.

Make the AI features functional, not just visual mockups.

Keep everything connected as one cohesive platform.

GOAL

Create a polished, presentation-ready AI workplace platform that demonstrates functionality, strong prompt engineering, innovation, responsible AI and professional UI/UX.
